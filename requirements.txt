# Deep Research Agent — 核心运行依赖（API / worker / 容器镜像）
#
# 这一份**刻意不含 torch 系**。模型服务化（v0.2.0）之后，配了 MODEL_SERVICE_URL 的
# API 与 worker 全程通过 HTTP 调用模型服务，进程内不 import torch/transformers
# （实测每 worker commit 6.9GB→0.75GB）。装上反而会让容器镜像多出约 5GB，并且让
# 「模型服务挂了」退化成静默的本地加载，而不是明确报错。
#
#   模型服务（需要 GPU 的那个进程）：pip install -r requirements-model.txt
#   开发/测试工具链：              pip install -r requirements-dev.txt
#
# 版本一律用 >= 承自既有约定。容器要完全可复现的话，另出一份 pip-compile 的锁文件，
# 不要就地改成 ==，那会影响宿主机上已有的 conda 环境。
